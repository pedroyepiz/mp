Estructuras de control de selección

Toma de decisiones mediante condiciones lógicas: selección básica, doble, múltiple y anidada.

Evaluar una condición permite elegir el camino correcto para resolver un problema.
Propósito: identificar y aplicar estructuras de selección para resolver problemas en los que una decisión modifica el flujo del algoritmo.
Competencia oficial.
Aplicar las estructuras de selección, mediante la propuesta de soluciones, para resolver problemas de ingeniería donde se requiere la toma de decisión, con una actitud analítica, propositiva y responsable.

Una estructura de selección permite que un algoritmo no ejecute siempre el mismo camino. Primero se evalúa una condición lógica; después, según el resultado, se ejecuta una alternativa. En PSeInt utilizaremos principalmente Si...Entonces...FinSi, Si...Entonces...SiNo...FinSi y Segun...Hacer.

¿QUÉ ES UNA ESTRUCTURA DE SELECCIÓN?

Es una estructura de control que permite tomar una decisión a partir de una condición. Una condición se evalúa como Verdadero o Falso, y con base en ese resultado el algoritmo decide qué instrucciones ejecutar.

📥 Datos
edad, número, promedio, opción...
→
◇ Condición
¿Verdadero o Falso?
→
🛣️ Camino
Ejecutar la alternativa correspondiente

3.1 Selección básica

Ejecuta una acción solamente cuando la condición es verdadera.

3.2 Selección doble

Permite elegir entre dos alternativas: una por verdadero y otra por falso.

3.3 Selección múltiple

Selecciona una opción entre varios valores discretos mediante Segun...Hacer.

3.4 Anidación

Coloca una decisión dentro de otra para resolver situaciones con más niveles de análisis.

3.1 · SELECCIÓN CONDICIONAL BÁSICA

La selección básica ejecuta un bloque únicamente cuando la condición es verdadera. Si la condición es falsa, el algoritmo continúa con la siguiente instrucción.

PSeInt · Sintaxis básica
Si condicion Entonces
    // instrucciones que se ejecutan si la condición es verdadera
FinSi

Ejemplo: mostrar un mensaje si una persona es mayor de edad

PSeInt · Selección simple
Proceso MayorDeEdadSimple
    Definir edad Como Entero

    Escribir "Ingresa la edad:"
    Leer edad

    Si edad >= 18 Entonces
        Escribir "Es mayor de edad"
    FinSi

    Escribir "Fin del algoritmo"
FinProceso

3.2 · SELECCIÓN CONDICIONAL DOBLE

Se utiliza cuando existen dos caminos mutuamente excluyentes. Si la condición es verdadera se ejecuta el primer bloque; si es falsa, se ejecuta el bloque SiNo.

PSeInt · Sintaxis doble
Si condicion Entonces
    // camino verdadero
SiNo
    // camino falso
FinSi

Ejemplo: determinar si un número es PAR o IMPAR

PSeInt · PAR / IMPAR
Proceso ParImpar
    Definir numero Como Entero

    Escribir "Ingresa un número entero:"
    Leer numero

    Si numero MOD 2 = 0 Entonces
        Escribir "PAR"
    SiNo
        Escribir "IMPAR"
    FinSi
FinProceso

3.3 · SELECCIÓN CONDICIONAL MÚLTIPLE

La selección múltiple es útil cuando una variable puede tomar varios valores discretos y cada valor corresponde a una acción diferente. En PSeInt se utiliza Segun...Hacer. Para rangos o expresiones lógicas complejas, normalmente conviene usar Si y SiNo.

PSeInt · Sintaxis Segun
Segun opcion Hacer
    1:
        // instrucciones de la opción 1
    2:
        // instrucciones de la opción 2
    De Otro Modo:
        // opción no contemplada
FinSegun

Ejemplo: calculadora de operaciones básicas

PSeInt · Calculadora con Segun
Proceso CalculadoraBasica
    Definir num1, num2, resultado Como Real
    Definir opcion Como Entero

    Escribir "Ingresa el primer número:"
    Leer num1
    Escribir "Ingresa el segundo número:"
    Leer num2

    Escribir "1. Suma"
    Escribir "2. Resta"
    Escribir "3. Multiplicación"
    Escribir "4. División"
    Leer opcion

    Segun opcion Hacer
        1:
            resultado <- num1 + num2
            Escribir "Resultado: ", resultado
        2:
            resultado <- num1 - num2
            Escribir "Resultado: ", resultado
        3:
            resultado <- num1 * num2
            Escribir "Resultado: ", resultado
        4:
            Si num2 <> 0 Entonces
                resultado <- num1 / num2
                Escribir "Resultado: ", resultado
            SiNo
                Escribir "No se puede dividir entre cero"
            FinSi
        De Otro Modo:
            Escribir "Opción no válida"
    FinSegun
FinProceso

3.4 · ANIDACIÓN

Anidar significa colocar una estructura de selección dentro de otra. Se utiliza cuando una segunda decisión solo tiene sentido después de conocer el resultado de una primera decisión.

Idea clave: la anidación no es una instrucción distinta; es una forma de combinar estructuras Si, SiNo o incluso Segun para direccionar el flujo.

Ejemplo: evaluación de calificaciones

Leer tres calificaciones, calcular el promedio y mostrar: Reprobado si el promedio es menor de 60, Aprobado si está entre 60 y 99, y Excelente si es 100.

PSeInt · Selección anidada
Proceso EvaluacionCalificaciones
    Definir c1, c2, c3, promedio Como Real

    Escribir "Ingresa tres calificaciones:"
    Leer c1, c2, c3

    promedio <- (c1 + c2 + c3) / 3

    Si promedio < 60 Entonces
        Escribir "Reprobado"
    SiNo
        Si promedio = 100 Entonces
            Escribir "Excelente"
        SiNo
            Escribir "Aprobado"
        FinSi
    FinSi

    Escribir "Promedio: ", promedio
FinProceso

EJEMPLO RESUELTO · MAYOR O MENOR DE EDAD

Problema

Pedir la edad de una persona y responder si es mayor o menor de edad.

ENTRADA edad
PROCESO Evaluar si edad >= 18.
SALIDA “Mayor de edad” o “Menor de edad”.

Decisión: como existen dos resultados posibles, corresponde utilizar una selección doble.

PSeInt · Ejemplo resuelto
Proceso MayorOMenorDeEdad
    Definir edad Como Entero

    Escribir "Ingresa tu edad:"
    Leer edad

    Si edad >= 18 Entonces
        Escribir "Mayor de edad"
    SiNo
        Escribir "Menor de edad"
    FinSi
FinProceso

💡
EN RESUMEN
La selección básica responde a una sola condición; la doble permite elegir entre dos caminos; Segun...Hacer facilita la selección entre varios valores discretos y la anidación permite tomar decisiones por niveles. La elección de la estructura depende de la forma del problema.
