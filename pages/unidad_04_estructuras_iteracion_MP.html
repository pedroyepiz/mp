Estructuras de control de iteración

Repetición controlada de tareas mediante contadores, acumuladores, centinelas y ciclos anidados.

Un ciclo repite una tarea mientras exista una condición que controle su ejecución.
Propósito: comprender y aplicar estructuras repetitivas para resolver problemas donde una misma tarea debe ejecutarse varias veces de forma controlada.
Competencia oficial.
Aplicar las estructuras de repetición, mediante la propuesta de soluciones, para resolver problemas de ingeniería donde se requiere la iteración de tareas, con una actitud analítica, propositiva y responsable.

Las estructuras de iteración permiten repetir instrucciones sin escribirlas muchas veces. Para construir un ciclo correctamente debemos identificar qué inicia el proceso, qué se repite, qué cambia en cada vuelta y qué condición provoca que el ciclo continúe o termine.

4.1 · TEORÍA DE CICLOS

Un ciclo es una estructura que permite repetir un bloque de instrucciones. Todo ciclo debe tener un mecanismo que controle su ejecución para evitar repeticiones infinitas.

🚦 Inicio
Inicializar variables
→
🔁 Repetición
Ejecutar instrucciones
→
🛑 Condición
Continuar o terminar
🔢

Contador

Variable que aumenta o disminuye una cantidad conocida en cada repetición.

➕

Acumulador

Variable que conserva una suma o resultado acumulado a lo largo del ciclo.

🚩

Centinela

Valor especial que indica cuándo debe terminar un proceso repetitivo.

4.1.1 · CONTADORES

Un contador cambia de manera regular, normalmente de uno en uno. Es útil cuando deseamos saber cuántas veces ocurre algo o controlar un número determinado de repeticiones.

PSeInt · Contador
contador <- 0
contador <- contador + 1

4.1.2 · ACUMULADORES

Un acumulador guarda un total parcial que cambia en cada iteración. A diferencia del contador, el incremento no necesariamente es constante.

PSeInt · Acumulador
suma <- 0
suma <- suma + numero

4.1.3 · CENTINELA

Un centinela es un valor reservado para indicar que ya no habrá más datos. Por ejemplo, si se leen números positivos, se puede utilizar -1 como señal de terminación.

Importante: el valor centinela sirve para controlar el ciclo y normalmente no debe procesarse como un dato válido.

4.2 · CICLOS CONTROLADOS POR CONTADOR

Se utilizan cuando conocemos de antemano cuántas veces debe repetirse una tarea. En PSeInt, la estructura Para es la opción más natural.

PSeInt · Sintaxis Para
Para i <- 1 Hasta N Hacer
    // instrucciones
FinPara

Ejemplo: mostrar los números del 1 al 10

PSeInt · Conteo del 1 al 10
Proceso ContarDel1Al10
    Definir i Como Entero

    Para i <- 1 Hasta 10 Hacer
        Escribir i
    FinPara
FinProceso

4.3 · CICLOS CONTROLADOS POR CENTINELA

Se utilizan cuando no conocemos cuántas veces se repetirá el proceso. El ciclo termina cuando aparece un valor especial definido previamente.

PSeInt · Ciclo Mientras con centinela
Proceso LeerHastaCentinela
    Definir numero, suma Como Entero

    suma <- 0

    Escribir "Ingresa un número (-1 para terminar):"
    Leer numero

    Mientras numero <> -1 Hacer
        suma <- suma + numero

        Escribir "Ingresa otro número (-1 para terminar):"
        Leer numero
    FinMientras

    Escribir "Suma total: ", suma
FinProceso

4.4 · ANIDACIÓN

La anidación de ciclos consiste en colocar una estructura repetitiva dentro de otra. Por cada vuelta del ciclo externo, el ciclo interno completa todas sus repeticiones.

PSeInt · Ciclos anidados
Proceso TablaCoordenadas
    Definir i, j Como Entero

    Para i <- 1 Hasta 3 Hacer
        Para j <- 1 Hasta 3 Hacer
            Escribir "i = ", i, "  j = ", j
        FinPara
    FinPara
FinProceso
Idea clave: si el ciclo externo se repite 3 veces y el interno 4 veces, el bloque interno se ejecutará 3 × 4 = 12 veces.

EJEMPLO RESUELTO · PROMEDIO DE 5 CALIFICACIONES

Problema

Leer 5 calificaciones, acumularlas y calcular el promedio.

ENTRADA 5 calificaciones.
PROCESO Repetir 5 veces, acumular las calificaciones y dividir la suma entre 5.
SALIDA Promedio final.

Selección del ciclo: como sabemos que son exactamente 5 datos, utilizamos un ciclo controlado por contador.

PSeInt · Ejemplo resuelto
Proceso PromedioCincoCalificaciones
    Definir i Como Entero
    Definir calificacion, suma, promedio Como Real

    suma <- 0

    Para i <- 1 Hasta 5 Hacer
        Escribir "Ingresa la calificación ", i, ":"
        Leer calificacion

        suma <- suma + calificacion
    FinPara

    promedio <- suma / 5

    Escribir "Promedio: ", promedio
FinProceso

Requisito: utilizar contador y acumulador.

Ejercicio 2 · Captura con centinela

Leer números enteros hasta que el usuario escriba -1. Al final mostrar cuántos números válidos se capturaron y su suma.

Requisito: utilizar un ciclo controlado por centinela.

💡
EN RESUMEN
Los ciclos controlados por contador se utilizan cuando conocemos el número de repeticiones; los ciclos controlados por centinela se usan cuando la cantidad de datos es desconocida. Los contadores controlan repeticiones, los acumuladores guardan resultados parciales y la anidación permite resolver problemas con repeticiones dentro de otras repeticiones.
